PROBLEM STATEMENT

The aim of this project is to create a Tic-Tac-Toe game using Python. A player can play against the computer. The game checks who wins or whether the game is a draw.


OBJECTIVES

- To create a game using Python.
- To allow the player to play against the computer.
- To check who wins the game.
- To find out when the game is a draw.
- To learn Python programming.


PROJECT DESCRIPTION

This project is a simple Tic-Tac-Toe game made using Python. The game has a 3×3 board. The player and computer take turns making moves. The computer selects its moves randomly. The game ends when someone wins or when the board is full


TECHNOLOGIES TOOLS

- Python
- Random module
- Lists
- Loops
- Functions
- If-else statements
