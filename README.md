📌 Problem Statement

The aim of this project is to develop a simple and interactive Tic-Tac-Toe game using Python. The game allows a player to compete against the computer on a 3×3 board. It automatically checks the game status and declares the winner or announces a draw when all positions are filled without a winner.

🎯 Objectives

✅ To develop a game using Python programming.

🤖 To allow the player to play against the computer.

🏆 To identify the winner based on the game rules.

🤝 To detect a draw when neither player wins.

🧠 To improve logical thinking and problem-solving skills.

💡 To understand basic Python programming concepts.

📝 Project Description

Tic-Tac-Toe is a classic two-player strategy game implemented in Python. In this project, the user plays against the computer using a 3×3 game board.

The player and computer take turns placing their symbols on the board. The computer chooses its moves randomly using Python's built-in random module.

The game continues until one player completes a winning combination or all the board positions are occupied. Finally, the program displays the result.

✨ Key Features

🎮 Interactive 3×3 game board

👤 Player versus computer gameplay

🤖 Random computer moves

🏆 Automatic winner detection

🤝 Draw detection

🔄 Turn-based gameplay

🐍 Simple Python implementation
